TAN DAT WILDCAT WEBSITE

This folder contains a complete four-page static website:
- index.html (Home)
- memberships-services.html
- meet-the-team.html
- contact.html
- styles.css

PREVIEW
Open index.html in a browser. All four pages are linked in the top navigation.

PUBLISH FREE WITH GITHUB PAGES
1. Sign in to GitHub and open the existing repository: valrussellrtr-eng/tandat-wildcat
2. Download/unzip this folder on your computer.
3. In the repository, upload the CONTENTS of this folder (not the enclosing folder) to the repository root. Replace old index.html and styles.css if prompted. Keep the four .html pages and README.
4. Commit the changes.
5. In GitHub, open Settings > Pages. Set the source to Deploy from a branch, choose main and /(root), then Save. If Pages is already enabled, wait for the new deployment.
6. Preview at https://valrussellrtr-eng.github.io/tandat-wildcat/ before changing your domain.

IMPORTANT
- Your Wix website and tandatwildcat.net DNS are not changed by these files.
- Original photos are referenced from their Wix-hosted image addresses so the recreated site can display them. Keep the original Wix site active while testing. If you later want all photos stored locally in this website, download the originals from Wix and place them in an assets folder, then update the image paths.
- Booking links currently use the public Square booking pages found on the original website. Please test each booking link before launch.
- This is a ready-to-publish static website, not a Silex visual-editor project. Editing text or layout later requires changing HTML/CSS or using a different visual editor that supports importing existing websites.
- Do not change the custom domain DNS until the GitHub Pages preview is approved. When ready, configure the custom domain in GitHub Pages and update only the required DNS records at Wix, preserving any email/MX records.

Homepage updates in this package: Permanent Jewelry feature, rotating photo slideshow, embedded Google map/directions, and customer review section.
